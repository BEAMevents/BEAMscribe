# BEAMscribe

Live open captions for events: live speech-to-text on a caption screen, with translation and NDI output. By [BEAM Events](https://beamevents.com).

This repository only holds the **Windows installers and updates**.

## Download
Get the latest version from **[Releases](https://github.com/BEAMevents/BEAMscribe/releases/latest)**:

- **BEAMscribe-Setup-x.y.z.exe** installs BEAMscribe and **updates itself automatically**. Use this one.
- **BEAMscribe-Portable-x.y.z.exe** runs without installing (e.g. from a USB stick). It tells you when a newer version is out, but doesn't update itself.

The installers aren't code-signed yet, so Windows SmartScreen may warn on first launch: click **More info → Run anyway**.

## Updates
The installed version checks for updates in the background and shows **Update x.y.z ready** in its header. Click it, then **Install & restart**. Updates never install while captioning is running.
